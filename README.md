# 日语语法通

日语动词、助词与单词学习网页。

- **在线访问**：<https://hyz322.github.io/jpstudy/>（把这个链接发给别人就能直接打开）
- **本地使用**：直接双击 `index.html` 用浏览器打开即可，不需要服务器、不需要联网。

## 功能

- **学习**：分「动词」「助词」两个科目。
  - 动词 24 课：动词分类、各种变形规则、相关句型、例句，变形表由程序自动生成；
  - 助词 18 课：10 个格助词及「は・も」、に/で、は/が 等辨析、助词叠用、N3~N1 复合格助词，以及动词与助词的固定搭配表；
  - 助词「用法总表」：13 个助词共 86 种用法（含同形的接续助词、终助词用法，如「が」表转折、「から」表原因），每种用法有词性、接续、说明和例句。
- **单词**：N5 共 716 词，按主题分组（可切换为按词性分组），支持汉字 / 假名 / 罗马音 / 中文搜索。
  - 每个词有假名、罗马音、浏览器朗读、中文释义、用法提示、2 个例句；
  - 读音怎么记：专门帮助记读音（语源、拆词、音读与中文发音的对应规律、谐音、联想），外来语以外的每个词都有；
  - 联想记忆：多种记法，最自然的一条标为「推荐」；
  - 词源拆解：能拆的词给出构词表格，并标可信度（构词明确 / 常见说法 / 语源有争议）；不能拆的词显示汉字解析（字义、音读、训读、含这个字的其他词）；外来语标出处；
  - 单词卡片：间隔重复（不认识的卡片本组内会再出现），可选日→中或中→日；
  - 单词可收藏、写笔记，收在复习本的「单词本」里。
- **助词查询**：点选助词查看全部用法，或输入中文关键词（如“原因”“对象”）跨助词搜索用法。
- **变形查询**：输入汉字 / 假名 / 罗马音 / 中文意思，查看动词的 20 种变形及规则说明；词库外的动词选类别后也能变形。
- **刷题**：
  - 可选科目：动词 / 助词 / 混合 / 单词；
  - 单词测验：按主题从 N5 词库自动出题，题型有看词选意思、看意思选词、汉字选读音、听发音选意思；
  - 手工编写的原创句子题：动词 200 题（每级 40）、助词 300 题，题型为选择 / 填空 / 排序，每题有答案、中文翻译和讲解；
  - 动词「变形题」：基于 258 个常用动词自动生成，可以无限刷；
  - 助词「搭配题」：从 115 组「名词＋助词＋动词」固定搭配中随机抽题（覆盖入门~进阶）；
  - 助词「辨析题」：从用法总表例句出题，判断句中助词属于哪种用法（共 168 道，覆盖全部难度）；
  - 练习模式（每题立即判分）和测验模式（整组做完交卷）；
  - 填空题可以直接打罗马音，自动转平假名。
- **复习本**：收藏、笔记、错题本（最近一次答错的题，答对后自动移出），可按科目和难度筛选；按科目、难度统计。

## 数据保存

收藏、笔记、做题记录、单词卡片进度保存在浏览器的本地存储（localStorage）中，只在当前浏览器有效。换浏览器 / 换电脑 / 清理浏览器数据前，请在「设置」里**导出备份**，之后再导入。

在线网页和本地双击打开的网页，数据是分开保存的；每个访问者的数据也只保存在他们自己的浏览器里，互不影响。需要把数据迁移到另一边时，同样用导出、导入。

## 在线发布（GitHub Pages）

网站托管在 GitHub 仓库 `hyz322/jpstudy` 的 `main` 分支根目录，开启了 GitHub Pages。修改代码后提交并推送即可更新线上网页（一般 1~2 分钟生效）：

```bash
git add -A && git commit -m "说明" && git push
```

- 根目录的 `.nojekyll` 让 GitHub 原样发布文件，不要删除；
- `.claude/` 已在 `.gitignore` 中排除；
- 本仓库的提交邮箱是 GitHub 匿名邮箱（只对本仓库生效）。

## 新增题目

按 `docs/题目数据格式.md` 的格式往对应的 `js/data/q_l*.js`（动词）或 `q_p*.js`（助词）中追加题目，然后运行：

```bash
python3 tools/validate_questions.py
```

## 新增单词

按 `docs/单词数据格式.md` 的格式新建或追加 `js/data/words_*.js`（新文件要在 `index.html` 里引入），单词里用到的新汉字补进汉字表，然后运行：

```bash
python3 tools/validate_words.py
```
