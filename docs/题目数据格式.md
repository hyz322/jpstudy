# 手工题目数据格式

题目文件位于 `js/data/q_l<难度>.js`，每个难度一个文件。文件内容固定为：

```js
JP.addQuestions(
[
  { ...题目1... },
  { ...题目2... }
]
);
```

中间的数组必须是**严格 JSON**（双引号、无尾逗号、无注释），以便 `tools/validate_questions.py` 校验。

## 难度

| level | 名称 | 对应 | 覆盖内容 |
|---|---|---|---|
| 1 | 入门 | N5 | 动词分类判断、ます形（ます/ません/ました/ませんでした）、〜ましょう、〜ませんか、〜たい、ます形+に行く、〜ながら |
| 2 | 基础 | N5~N4 | て形、た形、ない形、辞书形；〜てください、〜ている、〜てもいい、〜てはいけない、〜てから、〜たことがある、〜たり〜たりする、〜たほうがいい、〜ないでください、〜なければならない、〜なくてもいい、〜前に、〜ことができる、趣味は〜ことです |
| 3 | 进阶 | N4 | 可能形、意志形（〜ようと思う、〜つもり）、假定（ば/たら/と/なら）、命令形、禁止形、〜てみる、〜てしまう、〜ておく、〜てある、〜ように、〜ことにする/なる、样态〜そうだ、〜すぎる、〜やすい/にくい |
| 4 | 中级 | N3 | 被动（直接/间接/受害）、使役、使役被动、〜させてください、授受动词及て形授受、自他动词（〜ている/〜てある）、〜ようになる、〜たばかり、〜ところだ、〜ようとする、〜っぱなし |
| 5 | 高级 | N2~N1 | 敬语（尊敬语/谦让语/特殊敬语动词/お〜になる/お〜する/させていただく/(ら)れる尊敬）、复合动词（〜込む/〜出す/〜かける/〜切る/〜合う/〜直す/〜抜く/〜得る）、动词相关高级句型（〜ざるを得ない、〜ずにはいられない、〜かねる/〜かねない、〜つつ(も)、〜ようがない、〜わけにはいかない、〜てならない、〜てたまらない、〜んばかり、〜べく、〜まい、〜ものの、〜(よ)うにも〜ない、〜てやまない 等） |

## 字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | `L<level>-<三位序号>`，如 `L2-007`，全局唯一 |
| `level` | int | 1~5 |
| `type` | string | `choice`（四选一）、`input`（填空输入）、`order`（排序） |
| `topic` | string | 简短中文知识点标签，如 `て形`、`使役被动`、`谦让语` |
| `q` | string | 题干。日语句子中的空格用 `＿＿＿`。可在开头加中文提示，如 `（書く・て形）` |
| `options` | string[] | `choice`：4 个选项；`order`：4 个片段（打乱后的顺序）；`input` 不需要 |
| `answer` | int / string[] / int[] | `choice`：正确选项下标（0~3）；`input`：所有可接受的答案（平假名写法 + 常见汉字写法）；`order`：按正确顺序排列的 `options` 下标，如 `[2,0,3,1]` |
| `zh` | string | 完整正确句子的中文翻译 |
| `explain` | string | 中文讲解：为什么选这个、错误选项错在哪里、用到的变形规则。可以用 `\n` 换行 |

## 振假名

日语文字中的汉字可写成 `{漢字|かな}`，页面会渲染成 ruby 注音（可在设置中关闭）。只把汉字部分括起来，送假名放外面：`{書|か}く`、`{勉強|べんきょう}する`、`{先生|せんせい}`。

- 1~3 级：题干、选项中的所有汉字词都加注音。
- 4 级：N4 以上较难的汉字词加注音。
- 5 级：只给难读的词加注音。
- `input` 题的 `answer` 中**不要**使用 `{}` 标注。`explain` 和 `zh` 中可以不加。

## 示例

```json
{
  "id": "L2-001",
  "level": 2,
  "type": "choice",
  "topic": "て形",
  "q": "ここに{名前|なまえ}を＿＿＿ください。",
  "options": ["{書|か}いて", "{書|か}きて", "{書|か}って", "{書|か}んで"],
  "answer": 0,
  "zh": "请在这里写上名字。",
  "explain": "「〜てください」接动词て形。書く是一类（五段）动词，词尾「く」变て形时发生イ音便：く→いて，所以是「書いて」。「書きて」是把ます形词干直接加て，这是错误的；「って」是う・つ・る结尾的促音便；「んで」是む・ぶ・ぬ结尾的拨音便。"
}
```

```json
{
  "id": "L2-002",
  "level": 2,
  "type": "input",
  "topic": "ない形",
  "q": "（{飲|の}む・ない形）お{酒|さけ}は＿＿＿でください。",
  "answer": ["のまない", "飲まない"],
  "zh": "请不要喝酒。",
  "explain": "「〜ないでください」表示请求对方不要做某事。飲む是一类动词，ない形把词尾う段假名变成あ段再加ない：む→ま＋ない＝飲まない。"
}
```

```json
{
  "id": "L2-003",
  "level": 2,
  "type": "order",
  "topic": "〜たことがある",
  "q": "わたしは ＿＿＿ ＿＿＿ ＿＿＿ ＿＿＿。",
  "options": ["ことが", "{富士山|ふじさん}に", "あります", "{登|のぼ}った"],
  "answer": [1, 3, 0, 2],
  "zh": "我爬过富士山。",
  "explain": "「た形＋ことがある」表示曾经有过某种经历。语序：富士山に（地点）→ 登った（た形）→ ことが → あります。"
}
```

## 助词题

助词题放在 `js/data/q_p<难度>.js`，格式与动词题相同，区别：

- `id` 前缀为 `P`，如 `P2-007`；
- 每题必须有字段 `"subject": "particle"`；
- `q` 中的空格 `＿＿＿` 处填的是助词（可以是「には」「からも」这样的复合形式），`input` 题的 `answer` 写平假名助词即可，如 `["に"]`。

| level | 名称 | 对应 | 覆盖内容 |
|---|---|---|---|
| 1 | 入门 | N5 | は（话题）、が（存在/主语）、を（宾语）、に（时间点/目的地/存在场所）、へ（方向）、で（动作场所/手段）、と（和/一起）、の（所属/修饰）、も（也）、や（列举）、から・まで（起点/终点） |
| 2 | 基础 | N5~N4 | に vs で（场所）、に vs へ、を（经过/离开的场所：公園を散歩する・部屋を出る）、が（好き/上手/分かる/欲しい/できる 的对象）、に（动作对象：会う・電話する・あげる/もらう）、から/に（もらう 的来源）、より（比较）、と（引用：と言う/と思う）、で（原因/材料/范围/数量）、から vs で（原料/材料）、まで vs までに、ます形＋に行く（目的）、の（名词化：〜のが好き） |
| 3 | 进阶 | N4 | は vs が（新旧信息、疑问词＋が、从句里的が、对比的は）、连体修饰从句中 が→の、被动句施事的に、使役对象的に/を、と vs に（会う/結婚する/相談する）、に（变化结果：〜になる/〜にする）、で（状态/期限：一人で・三日で）、が（自动词）vs を（他动词）、には/では/とは/からも 等助词叠用 |
| 4 | 中级 | N3 | 复合格助词：について、に対して、にとって、として、によって（原因/手段/被动施事/因…而异）、によると、に関して、に比べて、に加えて、に沿って、を中心に、を通して/を通じて、に代わって、に従って、とともに |
| 5 | 高级 | N2~N1 | をめぐって、にわたって、にかけて、をもって、を問わず、に応じて、に基づいて、に先立って、に際して、をこめて、をはじめ（として）、にあたって、をきっかけに、を踏まえて、をもとに、に即して、をよそに、にひきかえ、をおいて |

示例：

```json
{
  "id": "P2-001",
  "level": 2,
  "subject": "particle",
  "type": "choice",
  "topic": "に vs で（场所）",
  "q": "{毎日|まいにち}{図書館|としょかん}＿＿＿{勉強|べんきょう}しています。",
  "options": ["に", "で", "を", "へ"],
  "answer": 1,
  "zh": "我每天在图书馆学习。",
  "explain": "「で」表示动作进行的场所……「に」表示存在的场所或移动的目的地……"
}
```

## 校验

```bash
python3 tools/validate_questions.py
```
