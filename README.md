# 日语语法通

本地离线的日语动词与助词学习网页，**直接双击 `index.html` 用浏览器打开即可**，不需要服务器、不需要联网。

## 功能

- **学习**：分「动词」「助词」两个科目。
  - 动词 24 课：动词分类、各种变形规则、相关句型、例句，变形表由程序自动生成；
  - 助词 18 课：10 个格助词及「は・も」、に/で、は/が 等辨析、助词叠用、N3~N1 复合格助词，以及动词与助词的固定搭配表；
  - 助词「用法总表」：13 个助词共 86 种用法（含同形的接续助词、终助词用法，如「が」表转折、「から」表原因），每种用法有词性、接续、说明和例句。
- **助词查询**：点选助词查看全部用法，或输入中文关键词（如“原因”“对象”）跨助词搜索用法。
- **变形查询**：输入汉字 / 假名 / 罗马音 / 中文意思，查看动词的 20 种变形及规则说明；词库外的动词选类别后也能变形。
- **刷题**：
  - 可选科目：动词 / 助词 / 混合；
  - 手工编写的原创句子题：动词 200 题（每级 40）、助词 300 题，题型为选择 / 填空 / 排序，每题有答案、中文翻译和讲解；
  - 动词「变形题」：基于 258 个常用动词自动生成，可以无限刷；
  - 助词「搭配题」：从 115 组「名词＋助词＋动词」固定搭配中随机抽题（覆盖入门~进阶）；
  - 助词「辨析题」：从用法总表例句出题，判断句中助词属于哪种用法（共 168 道，覆盖全部难度）；
  - 练习模式（每题立即判分）和测验模式（整组做完交卷）；
  - 填空题可以直接打罗马音，自动转平假名。
- **复习本**：收藏、笔记、错题本（最近一次答错的题，答对后自动移出），可按科目和难度筛选；按科目、难度统计。

## 数据保存

收藏、笔记、做题记录保存在浏览器的本地存储（localStorage）中，只在当前浏览器有效。换浏览器 / 换电脑 / 清理浏览器数据前，请在「设置」里**导出备份**，之后再导入。

## 目录结构

```
index.html              页面入口
css/style.css           样式
js/core.js              全局命名空间与工具函数
js/conjugate.js         动词变形引擎（变形 + 中文规则讲解）
js/drill.js             动词变形题自动出题
js/pdrill.js            助词搭配题、用法辨析题出题
js/kana.js              罗马音转假名、答案归一化
js/store.js             本地存储（收藏 / 笔记 / 记录 / 设置）
js/app.js               页面渲染与交互
js/data/verbs.js        动词词库、自他动词对、特殊敬语动词
js/data/lessons.js      动词讲义（也提供讲义排版工具 JP.lessonKit）
js/data/lessons_particle.js  助词讲义
js/data/collocations.js 动词与助词的固定搭配
js/data/particle_usages.js  助词用法总表（及辨析题的互斥对）
js/data/q_l1~q_l5.js    动词各难度手工题目
js/data/q_p1~q_p5.js    助词各难度手工题目
docs/题目数据格式.md     题目数据格式说明（新增题目时参考）
tools/validate_questions.py  题目数据校验脚本
```

## 新增题目

按 `docs/题目数据格式.md` 的格式往对应的 `js/data/q_l*.js`（动词）或 `q_p*.js`（助词）中追加题目，然后运行：

```bash
python3 tools/validate_questions.py
```
